# 多实例负载不均

## 故障现象
部分实例 GPU 满载、队列很长，其他实例空闲；整体平均指标正常但单实例 P99 和 5xx 很高。

## 需要检查的指标和日志
按 instance_id 查看请求数、active/waiting、GPU 利用率、显存、TTFT、P99、连接数和负载均衡器 access log。

## 排查步骤
检查 sticky session、长连接、健康检查、权重和实例注册时间；确认某些实例是否被标记 healthy 但实际 worker 不可用；比较请求 token 分布。

## 修复建议与验证
修正健康检查和权重，缩短失效实例摘除时间，避免不必要的会话粘性；扩缩容后观察每个实例分布接近均衡且尾延迟下降。
