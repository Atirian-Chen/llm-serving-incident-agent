# 节点故障与网络问题

## 故障现象
单节点实例全部超时或下线，多节点 TP 通信变慢；应用错误可能表现为 5xx、NCCL timeout 或连接 reset。

## 需要检查的指标和日志
检查节点心跳、GPU Xid/ECC、网卡丢包、RTT、带宽、kubelet/container runtime、DNS、路由和负载均衡器日志。

## 排查步骤
比较故障节点与健康节点，执行连通性、端口、DNS 和 NCCL 链路检查；确认故障时间是否与驱动、内核或网络变更一致。

## 修复建议与验证
摘除故障节点并迁移流量，修复路由/网卡/驱动后再回池；为健康检查增加真实推理探针。逐步恢复并验证跨节点吞吐、P99 和错误率。
