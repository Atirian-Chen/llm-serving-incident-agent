# TTFT TPOT 与 P99 延迟

## 故障现象
用户报告首 token 慢或整体生成变慢，P99 远高于 P50，且错误率可能保持正常。长尾常来自少数超长请求或重试风暴。

## 需要检查的指标和日志
检查 request latency、TTFT、TPOT、P50/P95/P99、queue time、input/output token 分布、超时数和 retry count，并关联请求 trace_id。

## 排查步骤
按实例、模型、租户、输入长度和时间窗口切片；区分服务端处理、网络传输和客户端等待；检查是否发生队列积压、实例重启或 GC。

## 修复建议与验证
设置合理的超时与最大 token，优化队列和批处理并抑制重复重试。验证 P99、超时率和吞吐在稳态窗口内同时达标。
